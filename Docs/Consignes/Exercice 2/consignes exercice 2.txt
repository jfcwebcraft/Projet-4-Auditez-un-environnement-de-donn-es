Étapes
Vous devez intégrer les logs dans votre base de données, comprendre les nouvelles entrées et le format de ces données. 

 

Prérequis 

Avoir inséré les logs, vérifié les types de données et la qualité de l’information insérée.
Résultat attendu  

Les logs intégrés.
Instructions  

Créez la table dans votre base de données (manuellement, avec SQL Power Architects ou directement en SQL dans votre base).
Insérez les données CSV.
Vérifiez les types et les données insérées dans la base.
Recommandations 

Prenez le temps de comprendre les données de logs.
 

Prenez le temps de bien analyser les logs en croisant les données.

 

Prérequis 

Avoir analysé le type de données du fichier logs.
Avoir compris les fonctions INSERT, UPDATE et DELETE en SQL.

Votre fichier au format PPT mis à jour et contenant les requêtes SQL utilisées pour comprendre vos logs.
Recommandations  

N’hésitez pas à faire des requêtes SQL en utilisant les tables qui existent déjà dans la base de données. Ainsi vous allez pouvoir comprendre plus facilement les données.
